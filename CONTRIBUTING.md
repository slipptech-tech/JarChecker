# Contributing to JarChecker

First off, thank you for taking the time to contribute! 🎉 Whether it's reporting a bug, improving documentation, or submitting a feature request, all contributions are greatly appreciated.

Please take a moment to review the guidelines below to help make the contribution process smooth for everyone.

---

## 🧭 How Can I Help?

### 1. Reporting Bugs
If you find a bug in the code, please open an issue. To help us fix it as fast as possible, include:
* **A clear and descriptive title** of the issue.
* **Steps to reproduce** the bug (what you did, what happened, and what you expected to happen).
* **Environment details** (OS, Java version, or any other relevant technical context).
* **Logs or screenshots** if applicable.

### 2. Suggesting Enhancements
Have an idea for a new feature or improvement? 
* Open an issue and select the enhancement template (or just describe your idea clearly).
* Explain **why** this feature would be useful and how it should work.

### 3. Pull Requests (Submitting Code)
We welcome pull requests! If you want to fix a bug or add a new feature:
1. **Fork** the repository and create your branch from `main` (or `master`).
2. Give your branch a descriptive name (e.g., `fix/scan-timeout` or `feature/gui-update`).
3. Make your changes and write clean, readable code.
4. Test your changes locally to ensure nothing is broken.
5. Push your branch and open a **Pull Request (PR)** against our main branch.
