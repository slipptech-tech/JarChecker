# JarChecker
What is JarChecker?  JarChecker is a modern file analysis tool designed to help users inspect, understand, and verify the contents of files before opening them.  Originally built for Java JAR files and Minecraft mods.
## ⚠️ Antivirus Warning & False Positives

Because **JarChecker** is a newly released utility and is not yet signed with an expensive commercial digital certificate (Code Signing Certificate), some antivirus programs (like Windows Defender, SmartScreen, or third-party AVs) might flag it as an **Unknown Publisher** or a **False Positive**.

### Is it safe?
* **Yes, it is 100% safe.** The source code is fully open, and you can inspect every line of it right here in the repository.
* If you prefer not to use the pre-compiled binary releases, you can always clone the repository and build/run the project yourself.

### What to do if your antivirus blocks it:
1. **Windows SmartScreen (`Windows protected your PC`):** Click on **"More info"**, and then click **"Run anyway"**.
2. **Antivirus Alert:** Add the application to your antivirus exclusion list or check the file hash against VirusTotal before running.
## ✨ Key Features

* **📦 Package Structure:** Deep dive into the internal file tree of JAR files and Minecraft mods.
* **🛡️ Risk Assessment:** Automatic detection of suspicious elements and calculation of a total risk score.
* **🌐 Network Analysis:** Inspect outgoing connections, URLs, or potential web requests hidden inside the package.
* **🔍 File Diff:** Compare different versions of files to spot unauthorized or unexpected changes.
* **🤖 AI & Sandbox Insights:** Modern interface layout designed for quick data overview.

---

## 🚀 Quick Start / How to Use

1. Head over to the **[Releases](https://github.com/slipptech-tech/JarChecker/releases)** page.
2. Download the latest version of **JarChecker**.
3. Launch the application, click **"Open File"**, and select any `.jar` file or mod you want to inspect.
